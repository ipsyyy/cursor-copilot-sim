# Cursor vs Copilot — Multi-Agent Simulation

What actually happens inside a company the week a competitor launches something better?

I simulated the week Cursor hit 1 million paid users — inside the GitHub Copilot team.

## The Agents
- 🔴 Microsoft Executive — managing the narrative
- 🔵 Copilot PM — proposing three strategies
- 🟢 Lead Engineer — dropping the truth nobody wanted
- ⚫ GitHub CEO — asking the hard question
- 🔴 Satya Proxy — three lines. Kodak reference. Lands heavy.
- 🟡 Chief of Staff — the memo nobody else will write

## The Finding
The Engineer told the team it would take 6-12 months to close the gaps. Nobody addressed it directly.

The Chief of Staff named it on Monday of week 2:
> "Our structural bias towards enterprise narratives limits our ability to innovate at the pace required to captivate individual developers."

## Built With

## How To Run
1. Clone the repo
2. Add your API keys to .env
3. pip install -r requirements.txt
4. python main.py
